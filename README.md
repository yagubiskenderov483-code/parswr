# Гифт-трекер маркета Telegram

Ловит **только что выставленные** NFT-подарки на внутреннем маркете Telegram
и сразу постит карточку в канал `-1003784435307`.

## Фильтры (жёстко)

- цена **4500–27000 Stars** (цель 5000–25000, чуть дешевле/дороже ок)
- первый запуск обходит **все коллекции** и запоминает текущий рынок (в канал не постит)
- дальше каждый проход ловит **только новые** лоты
- level аккаунта **≤ 2**
- **только русские девочки** — кириллица в имени/био, ник, эмодзи
- один владелец — один пост (повторы режем)
- гифты в канал **в случайном порядке**, не пачкой одной коллекции
- максимум **12 NFT**
- писать можно **бесплатно** (не за Stars)
- между постами **5 секунд**

## Запуск

```bash
pip install -r requirements.txt
python3 main.py
```

Бот [@jsjeigiejwhnewbot](https://t.me/jsjeigiejwhnewbot):

1. Добавь бота админом в канал (право «Публикация сообщений»).
2. Напиши боту `/start` и войди в аккаунт (номер → код из приложения Telegram).
3. Трекер запоминает текущий рынок, дальше шлёт **только новые** лоты (русские девочки, рандом, пауза 5с).

Локально без бота: `python3 generate_session.py`.

Bothost запускает `python main.py`. Сессия лежит в `/app/data/tracker_session.txt`.
