# Гифт-трекер внутреннего маркета Telegram

Следит за **встроенным маркетом Telegram** (перепродажа NFT-подарков за звёзды),
моментально ловит новые листинги в заданном диапазоне цены (по умолчанию
**500–900 Stars**) и постит карточки в твой канал — с кнопками
«Занять», «Открыть лот», «Продавец».

Пример карточки:

```
🎉 НОВЫЙ ЛИСТИНГ

🎁 Гифт: Snoop Dogg
💲 Цена: 800 Stars / 8.16 TON
🏷 Модель: Long Beach
👤 Продавец: @seller (8266964603)
📶 Level: -1
📢 Сообщения: бесплатно
🕺 Статус: без Premium
🔗 SnoopDogg-264094
🕒 25.08.2026 15:53:09
```

## Как это работает

- Юзербот (твой Telegram-аккаунт через Telethon) опрашивает маркет методом
  `payments.getResaleStarGifts` — первая страница каждой коллекции содержит
  самые свежие листинги (сортировка по дате).
- Новые лоты, попавшие в диапазон `MIN_STARS..MAX_STARS`, уходят в канал.
- Если задан `BOT_TOKEN`, карточки шлёт бот (с inline-кнопками); иначе — сам
  аккаунт, без кнопок.
- Состояние (какие лоты уже видели) хранится в `tracker_state.json`.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env   # если .env ещё нет
```

Заполни в `.env`:

| Переменная | Что это |
|---|---|
| `API_ID`, `API_HASH` | с [my.telegram.org](https://my.telegram.org) → API development tools |
| `BOT_TOKEN` | токен бота от [@BotFather](https://t.me/BotFather) (для кнопок) |
| `TARGET_CHANNEL` | канал: `@username`, `-100…` id или инвайт-ссылка `https://t.me/+hash` |
| `MIN_STARS` / `MAX_STARS` | диапазон цены, по умолчанию 500–900 |

## Первый запуск

1. Добавь бота админом в канал (право «Публикация сообщений»).
2. Создай сессию юзербота (одноразово):

```bash
python3 generate_session.py
```

Скрипт спросит телефон, код из Telegram и пароль 2FA, затем сам запишет
`SESSION_STRING` в `.env`.

3. Запусти трекер:

```bash
python3 tracker.py
```

При первом запуске трекер запоминает все текущие лоты **без постинга**
(чтобы не заспамить канал), дальше шлёт только новые.

## Тонкая настройка

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `POLL_INTERVAL` | 2 | пауза между проходами, сек |
| `PAGE_LIMIT` | 12 | свежих лотов на коллекцию за проход |
| `PARALLEL` | 8 | параллельные запросы к маркету |
| `TON_RATE` | 0.0102 | курс TON за 1 Star для строки цены |
| `TZ_OFFSET` | 3 | часовой пояс времени в карточке (МСК) |

FloodWait от Telegram обрабатывается автоматически (трекер притормаживает).
Если ловишь много FloodWait — увеличь `POLL_INTERVAL` и уменьши `PARALLEL`.

## Деплой на Bothost

Bothost запускает **`python main.py`** — это только гифт-трекер. Старый
Neptun Parser (`bot_main.py`) **не стартует**, конфликта ботов больше нет.

Данные (сессия и состояние) хранятся в **`/app/data`**:

| Файл | Назначение |
|---|---|
| `/app/data/tracker_session.txt` | строка сессии Telethon |
| `/app/data/tracker_state.json` | уже увиденные лоты |

### Первый запуск на Bothost

1. Задеплой ветку с `main.py` (Bothost сам выполнит `python main.py`).
2. Добавь бота **@jsjeigiejwhnewbot** админом в канал (право «Публикация сообщений»).
3. В логах Bothost увидишь: «Напишите /start боту @jsjeigiejwhnewbot для входа».
4. Открой [@jsjeigiejwhnewbot](https://t.me/jsjeigiejwhnewbot) и отправь **`/start`**.
5. Введи номер телефона → код из Telegram → пароль 2FA (если включён).
6. После «✅ Вход выполнен» трекер сам продолжит: polling бота останавливается,
   сессия сохраняется в `/app/data/tracker_session.txt`, дальше идёт опрос маркета.

Повторный деплой сессию не сбрасывает — файл в `/app/data` переживает рестарты.

Альтернатива локально: `python3 generate_session.py` (запишет `SESSION_STRING` в `.env`).

## Замечания

- «Level: -1» — заглушка: такого поля нет в официальном API, сторонние
  трекеры считают его по своим базам.
- «Сообщения» и «Статус» берутся из API: можно ли писать продавцу бесплатно
  и есть ли у него Premium.
- `.env`, `tracker_state.json` и `tracker_session.txt` в git не попадают (см. `.gitignore`).
